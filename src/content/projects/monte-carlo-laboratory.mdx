This project turns probability limits into something visible. It includes experiments for estimating $\pi$, comparing estimators, and watching empirical distributions stabilize.

## Design principle

Each simulation pairs a visual trace with the mathematical object it estimates. The goal is not only to get an answer, but to see _how_ the answer emerges from randomness.

```python
inside = sum(x*x + y*y <= 1 for x, y in samples)
pi_estimate = 4 * inside / len(samples)
```

Future work includes variance-reduction methods and reproducible experiment snapshots.
